# ⚔️ Proyecto R - Equipo 10: *De Datos a Conocimiento*

## 🧠💡Objetivo
Procesar y explorar datos utilizando comandos de R vistos en el curso, hasta extraer insights que nos permitan **responder una pregunta de caracter descriptivo** mediante el análisis de datos.

## 📦 Dataset Principal
[Índice de Precios al Consumidor de Japón](https://www.kaggle.com/datasets/yutodennou/consumer-price-index-of-japan-by-2022)  
Un conjunto robusto de datos que abarca precios de productos en distintos rubros desde 1970. Ideal para explorar patrones de inflación a través del tiempo.

## 🔍 Ejemplos de Preguntas Poderosas

- 🎬 **Películas y éxito en taquilla**  
  ¿Qué factores convierten a una película en un éxito comercial?  
  Variables clave: género, presupuesto, director, recaudación.

- 🏦 **Transacciones bancarias y fraude**  
  ¿Qué patrones definen una transacción fraudulenta?  
  Variables: monto, ubicación, indicador de fraude.

- ⚽ **Ligas de fútbol y competitividad**  
  ¿Cuál es la liga más competitiva?  
  Métricas: diferencia de puntos entre rivales, número de goles, cantidad de partidos.

---

## 🌐 Nuestra Pregunta Elegida
**¿La inflación afecta de forma diferente a distintos rubros de productos?**  
Exploraremos cómo se comporta el Índice de Precios según el tipo de producto (alimentos, transporte, tecnología, etc.) y si algunos rubros son más vulnerables a los cambios económicos.

- Limpieza y visualización de datos 📊
- Uso de comandos en R: `tidyverse`, `ggplot2`, `dplyr`, entre otros.
- Análisis exploratorio y descriptivo 📈
- Conclusión basada en evidencia 🔍
